**CRWN-CLOTHING**

This is a solo project that I built after following a ReactJS course on Udemy platform called 'Complete React Developer'. This is a massive e-commerce application named Crwn-clothing which is built using key React features such as Redux, React Hooks, React Suspense, React Router, Context API, Redux-Saga, Styled-Components, Redux Toolkit.
In here serveless functions have been used to connect the frontend application with the Stripe third party library for the user payments in the e-commerce applications. 
For the Database and Authentication of the application Firestore and Firebase Auth Services has been used.
